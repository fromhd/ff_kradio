# ff_kradio (FlaskFarm K-Radio Plugin)

K-Radio 안드로이드 앱에서 사용할 수 있는 맞춤 채널 목록(`channels.json`)과 실시간 방송 편성표(`xmltv.xml`), 그리고 TV 방송의 온디맨드 오디오 스트리밍을 제공하는 FlaskFarm 플러그인입니다.

---

## 📌 주요 기능

1. **On-Demand 무변환 오디오 스트리밍**
   - TV 방송(티빙 등)의 고화질 비디오를 제외하고 **오디오 스트림만 실시간 복사(`-c:a copy -f adts`)**하여 K-Radio 앱에 전달합니다.
   - 앱에서 채널을 청취할 때만 `ffmpeg`가 백그라운드에서 동작하며, 청취를 멈추면 **즉시 프로세스가 종료**되어 저사양 미니 PC(N100 등)나 NAS에서도 CPU 부하가 0% 수준으로 유지됩니다.

2. **통합 EPG(실시간 방송 편성표) 자동 병합**
   - K-Radio 공식 라디오 XMLTV 편성표에 **네이버 TV 편성표(연합뉴스TV, YTN 등)**를 실시간으로 결합하여 단일 XMLTV 엔드포인트로 제공합니다.
   - 앱 화면에 현재 방송 중인 프로그램 제목이 실시간으로 표시됩니다.
   - 30분 단위 지능형 캐시가 적용되어 불필요한 네트워크 트래픽을 방지합니다.

3. **K-Radio 앱 전용 공개 엔드포인트 지원**
   - K-Radio 안드로이드 앱이 API Key 헤더나 파라미터를 지원하지 않으므로, 앱 연동에 필요한 엔드포인트(`channels.json`, `xmltv.xml`, `audio`, `logo`)는 인증 없이 다이렉트 접근이 가능하도록 구성되어 있습니다.

4. **웹 관리자 UI**
   - 플러그인 설정 화면에서 원하는 TV/라디오 채널을 손쉽게 추가, 수정, 삭제할 수 있습니다.
   - 채널 삽입 위치(특정 채널 뒤)를 지정하여 원하는 순서대로 배치할 수 있습니다.

## 🚀 기본 포함 채널

- **연합뉴스TV**
  - 소스: 티빙 라이브 (`C01723`)
  - EPG: 네이버 편성표 (`815508.naver`)
  - 로고: 1:1 전용 오렌지 정사각 아이콘
- **YTN**
  - 소스: 티빙 라이브 (`C00593`)
  - EPG: 네이버 편성표 (`814912.naver`)
  - 로고: 1:1 전용 블루 정사각 아이콘

## 🛠 설치 방법

FlaskFarm의 플러그인 폴더(`data/plugins` 또는 `plugins`) 아래에 본 레포지토리를 클론합니다:

```bash
cd /volume1/docker/ff/plugins # 또는 사용 중인 FlaskFarm 플러그인 디렉터리
git clone https://github.com/fromhd/ff_kradio.git
```

FlaskFarm을 재시작하면 자동으로 플러그인이 로드됩니다.

## 📱 사용 방법

1. **FlaskFarm 관리자 접속**
   - `플러그인 > K-Radio > 채널 관리` 메뉴로 이동합니다.
2. **설정 확인**
   - **DDNS 접속 주소**: K-Radio 앱이 외부에서 접속할 본인의 FlaskFarm 주소(예: `http://mydomain.com:8282`)를 입력합니다. (미입력 시 시스템 기본 DDNS 자동 참조)
   - **API Key**: 티빙 라이브 스트림 호출에 필요한 시스템 API Key를 입력합니다. (미입력 시 시스템 기본 API Key 자동 참조)
3. **K-Radio 앱에 주소 등록**
   - 관리 화면 상단의 **KRadio 앱 연동 주소**(`http://.../ff_kradio/channels.json`)를 복사합니다.
   - K-Radio 안드로이드 앱 실행 > **[설정]** > **[채널 설정 주소]** 항목에 붙여넣기 후 저장합니다.
   - 앱 목록을 새로고침하면 연합뉴스TV, YTN 등 추가된 채널과 실시간 편성표, 로고가 나타납니다.
